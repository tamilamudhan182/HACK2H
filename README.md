# Smart Event Companion

A mobile-first React + Vite experience for large venue attendees. The app combines a unified QR wallet, live crowd heatmaps, AI route suggestions, virtual queue management, group coordination, emergency alerts, and engagement rewards in one interface.

## Highlights

- Unified QR wallet for entry, food, merchandise, and transport use cases
- Simulated live crowd telemetry with congestion-aware route guidance
- Virtual queue cards with wait-time prediction and near-turn alerts
- Group locator, event timeline reminders, and departure recommendations
- Accessibility toggles for high contrast, larger text, and voice alerts
- Pure helper utilities with Node-based tests for wallet, queue, and alert logic

## Commands

```bash
npm install
npm run dev
npm run build
npm test
```
